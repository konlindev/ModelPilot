# Implement user authentication and basic permissions

- 时间：20260605-170414
- 分支：main-update-auth-20260605-170414
- 基准分支：main-update-openai-20260605-165927

## 主要变更

- 新增 API Key 鉴权，支持 `Authorization: Bearer` 和 `x-api-key`。
- 支持用户启用/禁用、模型 allowlist、IP allowlist/denylist、allowed_hours。
- 新增内存版频率限制和 token 日/月额度统计。
- `/v1/models` 现在需要鉴权，并只返回当前用户允许访问的 enabled 模型。
- `/v1/chat/completions` 增加鉴权、权限、频率和 token 额度检查。
- 增加 `tests/test_auth.py` 和 `tests/test_quota.py`。
