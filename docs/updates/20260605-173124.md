# Implement lightweight classifier-assisted routing

- 时间：20260605-173124
- 分支：main-update-classifier-20260605-173124
- 基准分支：main-update-smart-auto-20260605-172337

## 主要变更

- 实现 `app/classifier.py` 轻量分类器，支持 OpenAI-compatible 后端和 Ollama OpenAI-compatible base URL。
- 分类器要求返回严格 JSON，并解析为 `ClassificationResult`。
- 分类器失败、timeout、异常或非法 JSON 时返回 `None` 并回退 Phase 4 规则路由。
- `smart-auto` 路由先执行规则路由，再根据分类器高置信度建议调整 tier。
- high risk 分类结果至少使用 strong tier，最终仍检查用户 `allowed_models`。
- `modelpilot` 和日志新增 classifier 状态字段。
- 默认配置新增 `classifier.backend_model`、`classifier.timeout_seconds`、`classifier.min_confidence`。
- 新增 `tests/test_classifier.py`。
