## 主要变更

- 新增 `GET /v1/models`，返回 enabled 的真实模型和虚拟模型。
- 新增 `POST /v1/chat/completions`，支持非 streaming 的真实 enabled 模型直连转发。
- 新增 OpenAI-compatible 后端客户端，使用 `httpx.AsyncClient` 和显式 timeout。
- 对后端 OpenAI 格式响应注入 `modelpilot` 元数据。
- 对 `stream=true`、`smart-auto`、不存在或 disabled 模型返回明确错误。
- 增加 OpenAI 兼容接口测试和 httpx mock 转发测试。
