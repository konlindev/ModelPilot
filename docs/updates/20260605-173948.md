# Implement response validation and auto upgrade

- 时间：20260605-173948
- 分支：main-update-validation-20260605-173948
- 基准分支：main-update-classifier-20260605-173124

## 主要变更

- 实现 `app/validators.py` 响应校验。
- 增加 `ValidationResult`，包含 `passed`、`reason`、`severity`。
- 支持空响应、缺失 choices、空 content、最小长度、JSON 模式、禁词、竞品词、rate limit 和 context length 错误校验。
- 在 `router_engine.py` 中新增 `get_next_upgrade_model()`，按 `cheap -> mid -> strong` 查找下一档 enabled 且用户允许的模型。
- `smart-auto` 响应校验失败时可自动升级并重试。
- 自动升级受 `validation.auto_upgrade_enabled`、`user.allow_auto_upgrade` 和 `allowed_models` 约束。
- `modelpilot` 新增 `validation_passed`、`validation_reason`、`auto_upgrade_used`、`upgrade_chain`。
- 新增 `tests/test_validators.py`。
